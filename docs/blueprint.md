# **App Name**: Code Canvas

## Core Features:

- Visual Editor: Drag and drop interface for adding and arranging website components.
- Template Gallery: A selection of pre-designed website templates.
- Component Library: A library of pre-built website sections like headers, footers, and contact forms.
- AI Design Tool: AI tool that suggests design improvements based on current layout and style.

## Style Guidelines:

- Primary background: Rich black (#0D0D0D).
- Primary accent: Metallic gold (#D4AF37) for primary buttons and highlights.
- Accent: Teal (#008080) for interactive elements to provide a modern contrast.
- Clean, sans-serif fonts for readability.
- Modern, grid-based layout for easy content arrangement.
- Subtle animations and transitions for a smooth user experience.

## Original User Request:
# Code with Msmahatha: Dynamic Website Builder Platform

## Project Overview
Create a comprehensive web application called "Code with Msmahatha" that allows users to dynamically build attractive, professional websites without coding experience. The platform should combine the power of Firebase for backend functionality with an intuitive drag-and-drop interface, enabling users to create custom websites that meet their specific needs and aesthetic preferences.

## Branding
- **Name**: Code with Msmahatha
- **Tagline**: "Transform Your Vision into Reality"
- **Logo**: Stylized combination of code symbols and a website icon, using the black and gold color theme
- **Brand Voice**: Professional, empowering, and accessible

## Color Theme
- **Primary Background**: Rich black (#0D0D0D)
- **Primary Accent**: Metallic gold (#D4AF37) for primary buttons, highlights, and important UI elements
- **Secondary Accent**: Pale gold (#E6C670) for hover states and secondary elements
- **Tertiary**: Deep gold (#996515) for borders and dividers
- **Text Colors**:
  - White (#FFFFFF) for primary text on dark backgrounds
  - Light gray (#E0E0E0) for secondary text
  - Black (#000000) for text on gold elements
  - Gold (#D4AF37) for highlighted text and links

## Core Features

- **Visual Editor**: Advanced drag-and-drop interface for page building

- **Dynamic Data Binding**: Connect UI elements to data sources
